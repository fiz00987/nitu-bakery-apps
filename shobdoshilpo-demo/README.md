# Shobdo Shilpo — ecommerce demo

This is a separate, review-safe storefront concept for `shobdoshilpo.com`.
It does not replace the existing `website/` project.

## Included

- Premium home-and-lifestyle visual direction based on the current catalogue
- Real Shobdo Shilpo product imagery and representative prices
- Wall art, Islamic decor, frames, and kids/learning categories
- Product search and category filters
- Featured/price sorting
- Quick-view product modal
- Local wishlist and shopping bag
- Demo checkout interaction
- Responsive mobile layout with fixed bag/WhatsApp bar
- Keyboard search shortcut: `Ctrl/Cmd + K`

## Preview locally

From the repository root:

```bash
python3 -m http.server 4173
```

Open:

```text
http://127.0.0.1:4173/shobdoshilpo-demo/
```

The checkout is intentionally a demo and does not submit a live order.
